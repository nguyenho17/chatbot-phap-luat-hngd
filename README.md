# Chatbot AI hỗ trợ tư vấn Luật Hôn nhân và Gia đình

## 1. Giới thiệu
Hệ thống chatbot AI hỗ trợ tra cứu và tư vấn các quy định của Luật Hôn nhân và Gia đình Việt Nam, 
ứng dụng mô hình Retrieval-Augmented Generation (RAG).

## 2. Mục tiêu
- Hỗ trợ sinh viên và người dân tra cứu luật nhanh chóng
- Giảm sai sót khi tư vấn pháp lý cơ bản
- Ứng dụng AI trong lĩnh vực pháp luật

## 3. Công nghệ sử dụng
- Python
- OpenAI API / Gemini API
- FAISS / ChromaDB
- FastAPI
- JSON-based legal documents

## 4. Kiến trúc hệ thống
- Chuẩn hóa văn bản pháp luật
- Embedding và lưu trữ vector
- Truy xuất ngữ nghĩa
- Sinh câu trả lời dựa trên ngữ cảnh

## 5. Cấu trúc thư mục
(Mô tả ngắn gọn)

## 6. Hướng phát triển
- Mở rộng thêm các luật liên quan
- Tích hợp giao diện web
- Bổ sung tính năng trích dẫn điều luật
